# Google Play screenshot checklist

Capture these from the final signed/internal-test app build after replacing all draft legal pages and production placeholders. Use a real supported Android device or emulator, clean demo account, and original/licensed room photos. Do not fabricate AI results or show personal data.

## Suggested phone set

1. **Home / landing:** DreamSpace AI identity, concise home-design purpose, no debug or draft/legal placeholders.
2. **Interior redesign setup:** room photo input and visible style/palette/budget choices.
3. **Before-and-after result:** a real generated image pair with a clear comparison divider and no unsupported “perfectly preserves” claim.
4. **My Projects:** saved concept cards, favourites, and clear project organization.
5. **Cost Estimator:** INR total range with the indicative-estimate disclosure visible.
6. **Project report:** show the PDF report opened in a compatible viewer, with personal/project data removed.
7. **Profile and privacy:** profile settings and account deletion control, without displaying a real email address.

## Capture and review

- [ ] Confirm current Play Console screenshot count, aspect ratio, dimensions, file type, and device asset requirements before capture; those requirements can change.
- [ ] Capture at least one current phone form factor and tablet layout if the listing advertises tablet support.
- [ ] For App Store Connect, also capture the iPhone 6.9-inch and iPad 13-inch sets (the iOS target supports both); App Store requirements change, so verify sizes in App Store Connect before upload.
- [ ] Check status bar, safe-area spacing, text wrapping, image crop, loading/error states, and readable contrast.
- [ ] Use the same app version, API host, and feature configuration in every shot.
- [ ] Do not include fake testimonials, unreleased paid plans, API errors, sample account data, unsupported claims, or Android Studio/emulator chrome.
- [ ] Have product/legal review the listing screenshots against actual available features.
